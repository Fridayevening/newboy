### Failed

**Market SSE does not deliver data.** `GET /v1/market/stream` returns 200 with
`content-type: text/event-stream`, then delivers **0 bytes** and closes. The check
asks for ten minutes connected; it does not reach one second of payload.

**Market quotes are empty.** `GET /v1/market/quotes` returns `{"quotes":[]}`
after about ten seconds. So the market feature currently shows nothing at all —
it neither retains a previous value nor invents one.

Providers are Yahoo spark, TradingView's scanner and CoinGecko. From a home
connection Yahoo answers **429**; datacenter IPs are commonly blocked or rate
limited, which would explain both results. **The cause is not confirmed** — it
could equally be an upstream API change. Someone with Render log access can settle
it in a minute; it cannot be settled from outside.

This makes production step 6 ("re-run health, language, Work, Research, SSE and
Hotaru checks") a **partial pass at best**.

## Known limitations

1. **The market feature shows nothing.** Both the SSE stream and the quotes
   endpoint come back empty against the live API. See Checks above.
2. **The API runs on Render's free plan.** Measured 24.5 s wake after idle,
   2.2 s warm. Production step 4 says to move to an always-on plan "if cold starts
   are not acceptable". That change was not made, so the cold start is part of the
   public experience. Confirmed by Yanfei on 2026-09-23.
3. **Atlas free tier** — 0.5 GB, no full production backup, may pause.
4. **Asset weight** — about 42 MB under `public/`, including a roughly 23 MB audio
   file.
5. **Owner uploads are ephemeral** — no Render persistent disk or object storage.
6. **Laser Lab cannot render.** The image has no Blender; `blenderOk: false`. It
   reports that instead of failing.
7. **No staging environment appears to exist.** `render.yaml` defines one service,
   and that service is the live one.
8. **The API origin is not documented anywhere.** It was recovered from the
   deployed frontend bundle for this check. Worth recording in `DEPLOYMENT.md`.
