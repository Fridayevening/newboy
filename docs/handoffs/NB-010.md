## Known limitations

1. **The API runs on Render's free plan.** It sleeps after 15 idle minutes and
   takes about a minute to wake. Production step 4 says to move to an always-on
   plan "if cold starts are not acceptable". That change was not made, so the cold
   start is part of the public experience. Confirmed by Yanfei on 2026-09-23.
2. **Atlas free tier** — 0.5 GB, no full production backup, may pause.
3. **Asset weight** — about 42 MB under `public/`, including a roughly 23 MB audio
   file.
4. **Owner uploads are ephemeral** — no Render persistent disk or object storage.
5. **Laser Lab requires Blender**, which the image does not include; it should
   report unavailable rather than fail.
6. **No staging environment appears to exist.** `render.yaml` defines one service,
   and that service is the live one.
